# Security

Found a way to break or misuse Co-op Haven (for example the vote API)? Please report it privately first: open a private security advisory on https://github.com/cranebeaker/coop-anything/security/advisories/new, or message a maintainer on the Co-op Anything Discord. Include what the problem is, where, and how to reproduce it.

The mods listed on the site are separate projects: report problems in them to their own repositories.
